# Security policy

Vector Field Notes is an experimental app intended for local testing. It is not a hosted service and has no supported production deployment.

## Supported versions

| Version | Security updates |
| --- | --- |
| Latest commit on `main` | Best effort |
| Older commits and forks | Not supported |

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's [Security Advisories](https://github.com/Semooze/vector-database/security/advisories) page using **Report a vulnerability**, if that option is available.

If private reporting is unavailable, open a [GitHub issue](https://github.com/Semooze/vector-database/issues/new) asking for a private contact method. Do not put exploit details, credentials, or personal data in the public issue.

Include the affected commit, a description of the impact, and steps to reproduce the issue. Reports are reviewed on a best-effort basis; no response or fix time is guaranteed.

If you discover a real API key or other credential in the repository, report the exposure privately. If the credential is yours, revoke or rotate it with its provider immediately.
